🐙 GitHub Pages로 배포하는 방법

1️⃣ 리포지토리 생성

GitHub에 로그인한 뒤 New Repository를 눌러 새 저장소를 만듭니다. (예: speed-cooking)

2️⃣ index.html 파일 업로드

현재 파일의 전체 코드를 복사하여 파일 이름을 반드시 index.html로 생성한 뒤 업로드(Commit)하세요.

3️⃣ GitHub Pages 활성화

  1. 리포지토리 Settings 탭 이동
  2. 좌측 메뉴에서 Pages 클릭
  3. Build and deployment에서 Branch를 main (또는 master)으로 선택 후 Save

🎉 약 1~2분 뒤 나만의 게임 웹사이트가 완성됩니다!
